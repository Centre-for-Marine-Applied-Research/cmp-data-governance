CMAR Measurements

This page provides an overview of where and how salinity is measured through CMAR’s Coastal Monitoring Program.

Figures and values on this page include data collected up to the end of the 2022 field season. This data underwent preliminary quality control (QC).

Locations

CMAR has collected salinity data from 14 stations in 7 counties (Figure 1).

The stations in Inverness County are in the Bras d’Or Lake, which is a brackish estuary. The salinity measured at these stations is expected to be substantially different from salinity measured at marine stations.

Number of Observations

A large proportion of these records are from Guysborough County (34.5%), while a small proportion are from Annapolis (0.8%) and Lunenburg (1.5%) counties (Figure 2).

Depth

The salinity sensors are typically placed in relatively shallow positions on the string (Figure 3). All of the salinity measurements recorded at 10 m were collected at the two Inverness stations for a specific project.

Sensors

CMAR uses aquaMeasure SAL sensors to measure salinity in practical salinity units (PSU).

These sensors can be susceptible to biofouling, which can cause substantial drift in the measured data over time. Sensor drift is difficult to detect with QC tests (IOOS 2020), and CMAR does not currently test for sensor drift. Users should evaluate salinity data carefully before analysis. It may be beneficial to compare measurements from consecutive deployments (e.g., the end of one deployment and the beginning of the next) to highlight potential drift in the salinity sensors.
